# 一步 One Step｜GitHub Pages 體驗版

[開啟練習網站](https://hectornet.github.io/one-step-algebra-pages/)

七年級「一元一次方程式」3-1～3-3 的課後練習，提供是非、單選、多選與自行輸入答案。題目由原創模板生成，配合各能力的練習進度調整難度。

## 試用方式

1. 開啟網站，建立暱稱並選擇「學生操作」或「老師試用」。
2. 選擇能力，提交答案與理由；可檢查自己寫出的步驟。
3. 右側提供規則式概念與提示，不會替學生寫出原題解答。預設使用規則提示；可在「AI 連線設定」接上老師管理的後端。學生不需要 OpenAI API Key。
4. 右上「匯出紀錄」下載目前檔案的 JSON；老師檔案可在後台按模式及學生匯出 CSV／JSON。

## 資料儲存

學習進度及行為紀錄保存在目前瀏覽器的 IndexedDB。老師試用與學生操作分開標記；角色用於本機分類，並非帳號驗證。不同電腦或瀏覽器不會自動同步，老師需要請學生各自匯出紀錄。清除網站資料前請先匯出。

題庫和批改程式可由瀏覽器下載；本機進度可被修改。適用於小規模課後試用，不能作為受保護的考試或不可竄改的學習證明。難度門檻為試用參數，需配合學生實際表現持續調整。

## 部署及開發

這個儲存庫保存靜態網站、原創題庫及 `backend/` 的 AI 服務核心，沒有金鑰或使用者紀錄。`backend/` 需另外部署，GitHub Pages 不會執行它。GitHub Pages 從 `main` 分支的根目錄發布；更新靜態檔案後會自動部署。

本機預覽可執行 `python3 -m http.server 8000`，再開啟本機 8000 埠。直接以 `file://` 開啟 HTML 無法正確載入資料。數學檢查、紀錄交易、進度與引導規則的原始版本已通過 12 項自動測試，包含 1,056 個題目變式。

## AI 連線更新

已新增連線設定、模型 enum 驗證、失敗時的規則提示、請求去重及額度限制。**目前尚未配置 OpenAI 金鑰或發佈後端，AI 尚未啟用**；原有練習與紀錄可繼續使用。後端需求見 [backend/README.md](backend/README.md)。不能將 API Key 填進網站或前端建置產物。

Node.js 24 執行 `npm test` 與 `npm run check` 可驗證公開版本，GitHub Actions 也會執行。測試使用模擬模型與真實 SQLite，沒有付費 API 呼叫。
